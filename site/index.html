Tap the water to feed the koi. Tap and hold one to pet it. The stones change the music, food, scene and time of day.

Run it in the terminal

koi is a small koi pond simulator, meant to be calming and simple. It started as a terminal program, and this page runs the same code in the browser.

To run it in your terminal, paste the line for your system. It downloads koi from the latest release and checks it. Then run koi. It looks best in Ghostty or Kitty.

# Linux and macOS
curl -fsSL https://jeremybyu.github.io/koi/install.sh | sh

# Windows, in PowerShell
irm https://jeremybyu.github.io/koi/install.ps1 | iex
Or download the file for your system from the latest release

Linux, ARMaarch64-linux.tar.gz
macOSmacos.tar.gz
